# Contributing to Raptor Link

Thanks for helping improve Raptor Link.

## Ways to contribute

You can help by:

- reporting bugs
- testing new versions
- suggesting features
- sharing WLED / iCUE hardware configurations
- improving documentation
- proposing code changes when source code is available

## Bug reports

Before creating a new issue, check whether the same problem has already been reported.

Include as much useful information as possible:

- Raptor Link version
- Windows version
- WLED version
- Corsair iCUE version if relevant
- WLED controller model if known
- number of LEDs and segments
- steps to reproduce the issue
- expected behavior
- actual behavior
- screenshots or logs when useful

Do not include passwords, API keys, private credentials, or other sensitive information.

## Feature requests

Describe:

1. what you want to achieve
2. why it would be useful
3. how you imagine the feature working
4. whether it concerns WLED, iCUE, screen mapping, presets, or another part of Raptor Link

## Pull requests

If source code is published, keep changes focused and explain clearly what they change.

For larger changes, opening an issue first is recommended.
