# Security Policy

## Reporting a security issue

If you discover a security issue in Raptor Link, avoid posting sensitive technical details, credentials, or private network information in a public GitHub issue.

For ordinary bugs that do not expose sensitive information, use the public issue tracker.

## Local network information

Raptor Link communicates with WLED devices on the local network. When sharing screenshots or logs publicly, consider hiding:

- Wi-Fi credentials
- access tokens
- passwords
- public IP addresses
- private information unrelated to the bug

Private LAN addresses such as `192.168.x.x` are usually not sensitive by themselves, but they are rarely required in full for a bug report.
