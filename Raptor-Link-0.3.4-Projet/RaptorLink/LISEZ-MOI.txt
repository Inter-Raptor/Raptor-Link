RAPTOR LINK 0.3.4 BÊTA — Un projet de Vivien Jardot

INSTALLATION WINDOWS 64 BITS
1. Dans l'ancienne application, utilisez Quitter près de l'horloge (pas seulement la croix).
2. Lancez Raptor-Link-Setup-0.3.4.exe et choisissez le dossier.
3. Ouvrez Raptor Link. Vos réglages Aurora sont repris automatiquement sur le même compte Windows.
4. Enregistrez puis Démarrez. iCUE doit autoriser pythonw.exe dans ses réglages SDK pour les sources iCUE.
La configuration reste dans %LOCALAPPDATA%\AuroraWLED pour assurer la migration.
L'installation neuve se fait par défaut dans %LOCALAPPDATA%\Programs\RaptorLink.
Une mise à jour peut reprendre votre ancien dossier d'installation.
Le menu Démarrer, le raccourci bureau et le désinstalleur portent le nom Raptor Link.

DÉMARRAGE AUTOMATIQUE
Automatismes > Lancer avec Windows + Synchroniser automatiquement > Enregistrer.
La croix ferme l'interface ; l'application poursuit la synchronisation dans la zone de notification.
Quitter arrête le moteur. Profils et mode film sont accessibles près de l'horloge.
Le PC doit rester allumé, la session ouverte et l'application lancée pour les horaires et réveils.
Cette version ne réveille pas un PC en veille et ne s'exécute pas avant l'ouverture de session.

PRISE EN MAIN
Au premier lancement : Commencer / Plus tard / Ne plus proposer.
Réglages > Revoir le tutoriel permet de le reprendre.
L'assistant guidé vérifie le WLED puis aide à choisir une source.
Tester cet éclairage le fait clignoter trois secondes ; les horaires restent prioritaires.

SOURCES ET ZONES
iCUE : clavier, RAM, ventilateurs ou autres appareils uniquement si leurs LED sont exposées par le SDK Corsair.
Choisissez une ligne horizontale, verticale ou une sélection libre. Rien n'est écrit sur les appareils Corsair.
Effets locaux : arc-en-ciel, respiration, comète ou couleur fixe, sans dépendance à iCUE.
Écran : couleurs des écrans sélectionnés pour la zone, le long du tracé configuré dans Correspondance écran → LED.
Audio : sélection explicite d'une entrée d'enregistrement Windows dans Réglages.
Pour la musique du PC : entrée Mixage stéréo si le pilote la propose (à activer dans les réglages Son Windows).
Sinon : microphone ou entrée audio virtuelle configurée par l'utilisateur. Capture des sorties haut-parleurs, casque et HDMI intégrée via WASAPI loopback (PyAudioWPatch 0.2.12.8). Dans Réglages, choisissez Sortie Windows par défaut ou une sortie précise. La sortie par défaut est résolue au lancement de la capture. Relancez la synchronisation pour changer de sortie par défaut à chaud.
Aucune image ni aucun son n'est conservé. Les captures sont traitées localement.
Chaque zone dispose de luminosité, sens, décalage, répétition, fondu entre couleurs et vitesse/couleur pour les effets concernés.
La répartition spatiale iCUE utilise les positions du tracé pour échantillonner la liste des LED sélectionnées selon l'axe choisi.

HORAIRES ET RÉVEIL
Chaque fiche WLED possède une plage et des jours actifs. Les plages traversant minuit sont acceptées.
- Selon l'utilisation du PC : respecte l'inactivité et le verrouillage dans la plage.
- En continu : ignore l'inactivité ET le verrouillage dans la plage.
En dehors : extinction immédiate, même avec le mode film ou un réveil programmé.
Deux heures identiques correspondent à 24 h sur les jours cochés.
Réveil : une fois dans la minute choisie, pour la durée réglée, puis retour au mode normal.
Le réveil ignore l'inactivité mais respecte le verrouillage (hors mode continu) et la plage horaire.
Pas de rattrapage après une heure manquée. Le dernier réveil déclenché est mémorisé pour éviter un doublon après redémarrage.
Fondu d'allumage : au lancement et à la reprise après inactivité, de 0 à la luminosité réglée.
Fondu d'extinction : après inactivité/verrouillage. Les limites horaires et la sortie du programme restent prioritaires.
Mode film : ignore l'inactivité, jamais la plage horaire. Il est limité à la session de l'application.

PROFILS
Un profil mémorise tous les éclairages et leurs réglages de zones/horaires/réveil.
Les options générales (Windows, fondus, langue, entrée audio) restent communes.
La sélection d'un profil depuis l'icône Windows actualise l'interface si aucun brouillon n'est en cours.
Exporter permet de conserver une sauvegarde incluant les profils. Importer désactive le lancement automatique importé.

ROBUSTESSE
Un appareil absent est réessayé périodiquement sans interrompre les autres flux.
Une source iCUE manquante met la zone concernée au noir ; les autres zones poursuivent leurs effets.
Les changements d'identifiant iCUE sont réassociés par numéro de série ou modèle unique connu ; les ambiguïtés nécessitent un choix manuel.
Après un redémarrage du WLED, la connexion est revérifiée et le flux reprend avec un état de repli éteint.
En veille ou arrêt brutal du PC, le délai du flux temps réel WLED est de 2 secondes.
Ne lancez pas simultanément l'ancien pont ICUE-WLED et Raptor Link.

CORRESPONDANCE ÉCRAN → LED
Choisissez la source « Couleurs d’un ou plusieurs écrans » dans la zone. Sélectionnez l’écran principal, tous les écrans ou une sélection. Le plan permet aussi de cocher les écrans concernés. Leur disposition Windows est reprise automatiquement. Le mode « Déplacer les écrans » permet une disposition personnalisée par zone ; « Reprendre la disposition Windows » l’annule. Cela ne modifie pas Windows.
Chaque pastille LED prend la couleur à sa position dans l’image. Passez en mode « Dessiner / déplacer les points LED » et déplacez les gros points. Cliquez ailleurs pour ajouter un point ; double-cliquez un point pour le retirer. Ajouter ou retirer un point remet les quantités en répartition automatique ; les déplacer conserve vos quantités.
Activez « Indiquer le nombre réel de LED entre chaque point », puis renseignez chaque segment. Exemple : 5, 100 et 152 LED = 257 LED. Le total doit correspondre à la plage de la zone. Un segment de 0 LED représente un passage sans éclairage.
Enregistrez puis démarrez. Le plan affiche chaque LED de la zone sélectionnée. Cochez « Afficher l’image des écrans en direct » pour voir l’image analysée derrière le tracé. Les images restent en mémoire sur le PC et ne sont pas enregistrées. L’aperçu s’arrête au verrouillage. Le flux LED affiché représente les valeurs produites, sans retour matériel confirmant leur réception.
Les écrans sélectionnés forment une surface commune ; les espaces sans écran sont noirs. Un écran absent entraîne une zone noire et un diagnostic. Actualisez les écrans après un changement de branchement.
Pour une source iCUE normale ou un effet autonome, le plan montre la forme du ruban sans modifier les couleurs. L’option iCUE « Répartir selon le plan » permet une correspondance horizontale ou verticale parmi les LED sélectionnées.
